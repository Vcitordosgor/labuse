## ECARTS confirmés (revérifiés à la main sur 3 exemples)

### 1. `FAUX-CLIENT` · `F1.batiment_hauteur_lidar.egout_m.non_negatif`
- **exemples** : `97413000DC1454` egout_m=-15.7 · `97411000AB0300` egout_m=-15.0 · `97418000BC0364` egout_m=-10.6 (tous `methode='dalle'`)
- **attendu** : hauteur d'égout ≥ 0 — **obtenu** : 1 218 lignes avec egout_m < 0
- **cause** : la mesure LiDAR (MNS − MNT) devient négative quand le modèle de sol est au-dessus de l'emprise bâtie (terrain remblayé, débord, glitch vertical du MNT) ; `methode='dalle'` dans tous les cas. Hauteur d'égout servie telle quelle.
- **fichier** : `src/labuse/api/app.py:6424` (`"hauteur_egout_lidar_m": _lid["egout_m"]`, aucun clamp).

### 2. `FAUX-CLIENT` · `F1.batiment_hauteur_lidar.faitage_m.non_negatif`
- **exemples** : `97413000DC1454` faitage_m=-11.6 · `97413000DD1550` faitage_m=-4.8 · `97421000AR0022` faitage_m=-1.8 (tous `methode='dalle'`, parcelles **vivantes**)
- **attendu** : hauteur de faîtage ≥ 0 — **obtenu** : 44 lignes (44 sur parcelles vivantes) avec faitage_m < 0
- **cause** : même artefact LiDAR « dalle ». `faitage_m` sert de hauteur du bâti existant.
- **fichier** : `src/labuse/api/app.py:6423` (`"hauteur_faitage_lidar_m": _lid["faitage_m"]`) **et** `src/labuse/api/gabarit.py:43-63` — l'outil Gabarit affiche `hauteur_m = round(faitage_m, 1)` **sans aucun clamp** (une hauteur de bâti négative rendue au client).

### 3. `FAUX-CLIENT` · `F1.batiment_hauteur_lidar.faitage_m.hauteur_max300`
- **exemples** : `97418000AZ0417` faitage_m=53401.6 · `97418000AZ0128` faitage_m=53401.6 (les 2 seules ; mêmes `n_cellules=7240`, `code_mission='23LHDREUNION'`, `methode='dalle'` ; parcelles vivantes)

- **fichier** : `src/labuse/api/app.py:6423`, `src/labuse/api/gabarit.py:63`.

### 4. `ROBUSTESSE` · `F1.dpe_records.annee_construction.annee_bornee`
- **exemples** : `2568E0569173B` (maison, insee 97418, parcelle `97418000AW0434`) annee_construction=**1761** — unique violation

## Lecture
Les 3 premiers écarts sont le **même défaut unique** : les hauteurs LiDAR (`faitage_m`/`egout_m`)
sont servies **sans borne basse ni haute** alors que `methode='dalle'` produit des valeurs négatives
(terrain au-dessus du bâti) et, dans 2 cas, une cellule aberrante à 53 km. Ces hauteurs alimentent la
fiche (`hauteur_faitage_lidar_m`, `hauteur_egout_lidar_m`) ET l'outil Gabarit (hauteur du bâti existant,
`round(faitage_m,1)` non clampé). Un garde-fou `GREATEST(0, LEAST(faitage_m, 300))` au service, ou un
repli sur `hauteur_bdtopo_m` quand `methode='dalle'` donne un négatif, suffirait. Le 4ᵉ est une anomalie
source isolée (1 DPE ADEME à 1761).
