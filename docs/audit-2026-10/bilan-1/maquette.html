Règle du Bilan (BILAN-1). Rien n'entre dans le calcul que le client n'a pas posé. Pré-rempli seulement le Sourcé (surface cadastre, zonage, taux de TVA légaux), modifiable. Tout le reste est vide avec un repère LABUSE cliquable (Faisabilité, DVF neuf, outil Taxe, ratios de place). Aucune marge, aucun prix max, aucun export tant qu'un poste est vide : chaque poste est renseigné ou marqué « Sans objet ». Structure = le modèle promoteur, toutes ses lignes, dans son ordre. Le nom de la société du modèle n'apparaît nulle part. Dans l'app, tout calcul est fait par le moteur ; le JavaScript de la maquette ne sert qu'à la démonstration. Repères fictifs.
